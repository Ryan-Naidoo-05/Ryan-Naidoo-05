### **My Projects**
Here are a few things I’ve completed, showcasing my Data Science ability:  
- [Wine Quality Analysis](https://github.com/Ryan-Naidoo-05/Wine-Quality-Analysis): Performed EDA and used Machine Learning to plot a supervised segmentation algorithm onto a wine dataset. Utilised R and RMarkdown, aswell as ggplot, rpart and tidyverse to help me with my study and investigation into what makes wine good.
- [Coronary Artery Disease Predictor](https://github.com/Ryan-Naidoo-05/Heart-Disease-Predictor-): Completed my first full Data Science project, from Data Cleaning to Model Architecture and Evaluation. Used Jupyter Notebook and noteable libraries such as Pandas, Numpy and Statsmodels to place a Logistic Regression algorithm on a dataset, to classify absense/presence of Coronary Artery Disease. Tweaked the model threshold and minimised false negatives. Achieved 92.1% AUC score. Created a web-application to showcase the model using streamlit, where the user may select 3 features and predict whether they are showing presence of CAD.
